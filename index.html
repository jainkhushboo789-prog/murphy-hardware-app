    How to use this dashboard

    1. Start on Dashboard to review sales, stock and profit indicators.
    2. Use Sales to search transactions or add a demo sale.
    3. Use Inventory to identify parts at or below their minimum stock.
    4. Use Payments to compare cash/UPI/card collections and credit due.
    5. Record actual shop data and export backups regularly.

    Backup & Restore Keep your shop data safe

    Export a backup file regularly. Restore only a backup created by this dashboard.
